# What a run of each fixture costs, in pairs: one mutant asked of one target,
# which is one test process started. A pair is the unit because it is the same
# number on every machine, at every job count, under every load — a duration is
# not, and a thing measured in durations cannot be ratcheted.
#
# `whole` is what a run that asked every target about every mutant would start.
# `started` is what this engine starts. **This file may shrink and never grow.**
# A change that makes the engine start more processes for the same question is
# a change to argue for in a pull request, not one to notice in a graph later.
#
# The command is fixed so the number is: `run --tier all --offline --locked
# --jobs 1`, with the configuration the fixture carries and nothing else.
#
# fixture             whole  started
fixture-simple           33       11
fixture-coverage         42       14
fixture-unreached        16        4
fixture-baseline         51       15
