# Catch-all ledger. One name per line, sorted.
#
# This file may shrink and never grow. A catch-all over a set this repository
# closes is the arm that absorbs the next variant silently: the compiler stops
# asking where it goes, and the defect reads as English until somebody
# compares two outputs. Every line here is a place that has not been named out
# yet, and adding one is a reviewed exception rather than a decision anybody
# makes while writing.
#
# A name is `<file>::<item> over <Enum>, <n> arm(s)` and never a line number. A
# number says where a catch-all sits and nothing about what it absorbs, so
# changing the arm above one -- `Message::BuildFinished` to `Decision::Tests`,
# say -- moved the waiver onto a different closed set with no diff for anybody
# to read. That was measured rather than supposed: the gate exited 0 and every
# gate test passed. The three parts of a name change exactly when what is being
# waived changes, and an ordinary edit -- moving the code, renaming a binding,
# reformatting a body -- changes none of them.
#
# The arm count is part of the name because several arms absorbing one set in
# one item are one claim, and one more is a claim nobody read.
#
# A foreign enum is not in scope. The values of `syn::Expr` are not ours to
# list, so an arm standing for the rest is the handling rather than a default,
# and neither is a set whose own crate says it may grow: there the compiler
# asks for the arm and nobody chose it.
