# Catch-all ledger. One `path:line` per line, sorted.
#
# This file may shrink and never grow. An arm that catches everything left of
# a set this repository closes is the one that absorbs the next variant
# silently: the compiler stops asking where it goes, and the defect reads as
# English until somebody compares two outputs. Every line here is a place that
# has not been named out yet, and adding one is a reviewed exception rather
# than a decision anybody makes while writing.
#
# Only arms somebody could have left out are in scope, because a waiver
# against something the compiler demands asks a reviewer to have decided what
# they could not decide. Two kinds are therefore skipped before they ever
# reach this file, and neither is a waiver anybody may retire:
#
#   - An enum of ours that says `#[non_exhaustive]`, read from another crate.
#     An integration test is its own crate, which is why this file was 44 lines
#     of which 38 were not waivers at all.
#   - A match whose every variant-naming arm carries a guard. No variant is
#     covered unconditionally, so the rest has to be written down.
#
# A foreign enum is not in scope either. The values of `syn::Expr` are not ours
# to list, so an arm standing for the rest is the handling rather than a
# default.
